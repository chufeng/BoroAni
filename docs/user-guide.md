# Ani 电视版使用指南

## 2026-11-17 Codex 接续：搜索重试

以下说明对应当前源码；后面的旧版本记录仅供回溯。

- 详情页点「搜索资源」会优先使用短片名，必要时重试完整片名；例如「葬送的芙莉莲 第二季」先搜「葬送的芙莉莲」。手动输入搜索会先使用输入的原词。
- 当前源无结果后，自动按订阅顺序尝试其他已启用且受支持的源。每轮最多3个源、每源最多2个关键词；超时或HTTP/解析错误会直接转到下一源，不并发请求。
- 界面显示实际尝试过的源、关键词、条数或错误。单次尝试包含站点限速等待最多8秒，返回或取消会停止后续请求。
- 找到候选后会停止重试，当前源切换为命中源；后续选集和播放均使用这个源。短词可能命中多个季数，请先核对条目。
- 资料来源仍为 AniList。搜索改进同时保留此前按钮描边修复；安装状态及测试结果以 `docs/codex-handoff.md` 为准。

## 从哪里开始

电视主界面选择「发现番剧 · 新番 / 每日放送 / 榜单 / 搜索」。进入后默认显示发现首页，不是订阅配置页。上方六个独立入口：搜索番剧、当季新番、每日放送、榜单、源管理、使用帮助。CMS 和 Jellyfin 仍在电视主界面的独立入口。浏览与 Ani 播放不要求弹弹play AppID；弹幕等官方 API 能力另论。

## 不知道看什么

- 当季新番：按设备北京时间所在季度展示，可切换该季度三个月；每个月按 Bangumi 首播日期倒序。2026-11-15 所在季度为2026年10–12月，默认打开10月。指本季首播或计划首播，不表示今天上线，更不表示资源站已经更新。该动画目录也可能含短片、MV、剧场版，并非纯电视连续剧榜。
- 每日放送：读取 Bangumi calendar 按星期归组。星期一至星期日可切换；「今天」用 Asia/Shanghai 选星期。接口没有时刻与时区字段，页面照录站方星期，不擅自当成中国资源更新时间。
- 榜单：Bangumi 动画综合排名，目录参数 sort=rank，显示接口提供的排名和评分，不自行编排名，不是实时播放量榜。
- 条目：确认打开中文名、原名、首播、简介（提供时显示）；选择「用片名在所选已启用 Ani 源搜索」。

## 第一次配置资源源

「源管理」→导入公开默认订阅，或输入可信 Ani 订阅地址→启用受支持源→选择该源。订阅只是搜索与解析规则集合，源不是番剧目录；Bangumi 列表只是元数据，不能证明任何源有资源。只访问你有权访问的内容。旧配置更新安装后保留，无需清数据。

## 已知道番名

「搜索番剧」→确认输入框打开键盘→输入关键词→搜索。也可从条目详情一键带入片名。可编辑关键词，使用中文名或原名，或选择「换源」；每次只请求所选已启用、受支持 Ani 源，没有自动扫站。找到匹配条目后确认→选集→播放，沿用原有媒体代理、Ani电视标记与 SurfaceView 链路。

## 无结果怎么办

先看当前源和本次关键词。尝试中文/原名、删除季数与副标题、缩短成核心番名，再搜索；或手动换一个已启用源。返回0条只代表此源这次未匹配，不是全网没有。遇超时、HTTP错误或解析失败可重试/返回；需要动态脚本、登录、验证码、付费限制或 DRM 的页面不做绕过。

## 遥控、网络与离线

方向键移动，黄色边框表示焦点，确认选择；列表可随焦点滚动，文字说明也可获得焦点，长简介/帮助可翻阅。输入框按确认打开输入法，返回先关键盘，再返回上一级。请求中可取消。列表每页20条，底部加载更多，最多浏览到offset10000；每日放送按星期返回。

最终包内含2026-11-15约14:50 UTC（北京时间22:50）从官方 API 实际下载的10/11/12月第一页、综合排名第一页和周放送快照，页面明确标记采集时间及「非实时、尚未联网刷新」。不是伪造数据，也不是电视联网成功证据。当前电视访问 api.bgm.tv 直连超时，故默认可直接浏览这些真实快照；「刷新 / 联网重试」、后续分页和没有内置资料的详情需要网络可达。快照不会自动变成下一季度数据。

联网成功的本机缓存1小时，过期时重新请求，联网失败可回退离线缓存并显示时间；服务端也可能缓存。元数据客户端严格校验证书和hostname，旧安卓复用 AniTls 可信根；不使用 Unsafe 客户端、不降级HTTPS、不修改电视全局网络设置。
